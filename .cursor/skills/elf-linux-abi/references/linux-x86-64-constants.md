# Linux x86-64 and ELF constants (generated from local headers)

Evidence tags: `[observed]` extracted programmatically from the headers named below on the audit sandbox. These are values from one Linux header set, not a specification: **before wiring a number into the engine, re-check it against the kernel's `arch/x86/entry/syscalls/syscall_64.tbl` and UAPI headers** (or the headers on the target machine). The tables were generated by a script, not typed.

Provenance: `linux-libc-dev` 6.8.0-110.110 (`asm/unistd_64.h`, `asm-generic/errno*.h`, `asm-generic/mman*.h`, `asm/prctl.h`); `libc6-dev` 2.39-0ubuntu8.7 (`elf.h`).
